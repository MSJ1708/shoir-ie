## Status vocabulary

Use only **PASS**, **FAIL**, **BLOCKED**, **NOT RUN**, or **WAIVED**. PASS requires the exact acceptance test and matching evidence. BLOCKED means an external permission, identity, tenant, credential, approval or configuration is missing, or a mandatory prerequisite remains unresolved. NOT RUN means no valid test was executed. WAIVED is allowed only with a documented, authorized scope exclusion, risk acceptance, approver and expiry/review conditions. Skipped required tests are not PASS.
