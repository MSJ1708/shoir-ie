## Rollback planning minimum

Before any authorized production deployment, record the current deployed commit and configuration, the prior working build, environment-matched migration/Edge Function ordering, database backup and restore evidence, reversible deployment steps, credentials/session revocation plan, alert owner and decision threshold for rollback. Do not roll back only one component if app/schema/function contracts would become incompatible. Do not perform a production operation until the authorized owner approves the exact plan.
